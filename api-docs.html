Before you start

  1. Sign in and make sure your approved balance is available.
  2. Create one EVA API key in the customer dashboard.
  3. Copy it immediately—the full secret is shown only once.
  4. Send the key in the X-API-Key header.

Keep it secret: Store the EVA key only on your server or in an environment variable. Never expose it in browser JavaScript, screenshots, public repositories, or chat groups.

  -H "Content-Type: application/json" \
  -H "X-API-Key: eva_live_YOUR_KEY" \
  -d '{
    "prompt": "Explain this idea in three short points.",

Authentication and billing

You may also send Authorization: Bearer eva_live_YOUR_KEY. One active EVA key works across every currently enabled provider endpoint. The provider response includes an eva_usage 

{
  "eva_usage": {
    "request_id": "request-uuid",
    "charged_usd": 0.000100,
    "balance_usd": 9.999900,
    "model": "provider-model"
  }
}

Common responses

400 Bad RequestPrompt or request body is invalid.
401 UnauthorizedEVA key is missing, invalid, revoked, or inactive.
402 Payment RequiredBalance is insufficient for the request.
413 Too LargeThe request exceeds the current size limit.
429 Rate LimitedWait briefly and retry with backoff.
5xx Service ErrorProvider or gateway service is temporarily unavailable.
